## Try it out!
https://lyric-visualization-website.vercel.app/

## Functionality
1. Artist prediction, classifies lyrics by predicting the artist that would write them (artists limited to a set of 27 rappers).
2. Cluster explorer, visual map of a 3 level hierarchical clustering on the semantic meaning of song lyrics.
3. Similar songs, find songs semantically similar to given songs.

## Data
This uses the genius-song-lyrics dataset from sebastiandizon on Hugging Face.

I further narrowed the dataset to english songs, and only the ~230k most viewed songs on Genius.

## Analysis
(See the other lyric github repo for information on the artist prediction model).

Embeddings were generated by feeding solely the lyrical data into Google's Gemini Embedding 2.

Hierarchical clustering was generated through recursive Leiden clustering on lyrical embeddings, and names were given by feeding representative song lyrics, keywords, and structural data to an LLM.

## Stack
A basic React front end interacting with a Fastapi backend with an vector index.
